## 🌐 Live Interactive Prototypes

Access the live web prototypes directly in any modern browser:

* 🚀 **[Master Gateway Portal](https://neurocoderx.github.io/cue-living-lab/index.html)** (`index.html`): Overview of the 24H Living Lab system and interactive prototype index.
* 🌅 **[04: 24-Hour Home Living Lab Demonstration](https://neurocoderx.github.io/cue-living-lab/04_showcase_24h.html)** (`04_showcase_24h.html`): 5 key daily life scenarios (07:00 Wake-Up, 10:30 Study Focus, 16:30 Workout, 19:30 Study Shield, 22:15 Deep Sleep) with dual-mode Story & Neuroscience Literature Citations.
* 📱 **[05: Adolescent Mobile App Prototype](https://neurocoderx.github.io/cue-living-lab/05_teen_app.html)** (`05_teen_app.html`): Lightweight 5-tab self-regulation mobile prototype featuring in-ear voiceprint motivation agent, 3s breathing friction simulation, bidirectional peer kudos, and screen-off bedtime audio.
* 👨‍👩‍👧 **[06: Parent Guard & Co-Growth Console](https://neurocoderx.github.io/cue-living-lab/06_parent_console.html)** (`06_parent_console.html`): Flow shield protection, custom care reminders, smart home IoT manager, parenting coach scripts, and WHO 4D habit contracts.
